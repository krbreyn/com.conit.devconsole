In order to install and enable within a project:



* Copy the .dll and .dll.meta files within ./Plugins to $PROJECT\_FOLDER/Assets/Plugins



* Install the package using the package manager -> install from disk within the project.



* Create a new empty game object, and add a script component to it, using the DevConsole- > 'Developer Console' script.



* Pres Tilde/Backquote when in play mode to open the console.
